# AI Rules — Machine Learning (CAU)

This repository contains individual coursework for the Machine Learning
course. These rules reflect the AI-use policy presented in `Week1/` and the
instructions in each lab README.

## Permitted use

- Ask for explanations of concepts.
- Ask for debugging guidance and diagnostic advice.
- Look up library syntax or API usage.
- Use official documentation and tutorials as external sources.

## Prohibited use

- Submit AI-generated code as-is inside a `TODO` block.
- Share or receive code for an individual lab.
- Copy code from a classmate or a previous year's work.
- Modify tests, protected functions, or signatures when the lab README
  prohibits it.
- Submit work that the student cannot explain.

## Student responsibilities

- Understand and be able to explain every line of submitted code.
- Personally verify the code, results, assumptions, and limitations.
- Record every AI tool and external source used in the table at the end of
  `report.pdf`, including its purpose and what was modified or verified.
- Leave the table empty only if no AI tool or external source was used.

Being unable to explain one's own code may be treated as academic dishonesty.
Labs remain individual work even when AI is used within the permitted limits.

## Repository workflow rules

- Preserve skeletons, tests, and files marked `DO NOT MODIFY`.
- Do not replace a student's work with a complete AI-generated solution.
- Prefer explanations, guiding questions, diagnostics, and targeted checks.
- Never publish or push changes without the student's explicit request.
